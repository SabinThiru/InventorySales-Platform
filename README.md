# Inventory & Sales Platform

A Java and MySQL console application for managing products, customers, sales transactions, and inventory reports.

## Tech Stack

- Java
- MySQL
- JDBC
- Maven
- DataGrip
- IntelliJ IDEA

## Features

- View, add, update, and delete products
- View and add customers
- Create sales transactions
- Automatically reduce product stock after a sale
- Generate low-stock, sales history, and best-selling product reports

## Database Tables

- products
- customers
- sales
- sale_items
